## Reddit

**Title:** I built BeaverCanvas: SQL dashboards and reports inside DBeaver Desktop

I use DBeaver to explore data and wanted to turn query results into dashboards
and reports without leaving the desktop app, so I built BeaverCanvas.

It supports interactive charts and maps, independent SQL per widget, draggable
and resizable dashboards, and a visual report designer with tables and KPIs.
You can save reusable JSON/SQL templates, export offline HTML, or create an EML
draft with chart images. The plugin saves a draft; it does not send email.

It's an independent open-source beta for DBeaver Desktop Community, powered by
Apache ECharts. Windows and Linux are the current test targets; macOS and broad
driver/mail-client certification are still pending.

Source: https://github.com/michaaels/dbeaver_echart_plugin
