Comparte el reporte

Cada gráfico, su propia consulta.

Combina indicadores de distintas consultas en un dashboard. Edita el SQL de cada widget, elige sus campos y ajusta el espacio arrastrando sus bordes.

  • Gráficos de líneas, barras, dispersión, sectores y más.
  • Mapas con latitud y longitud, coordenadas o puntos GeoJSON/WKT.
  • Filtros compartidos, actualización y títulos automáticos.
Ver cómo configurar un mapa

Dale forma al reporte, sin empezar de nuevo.

Abre tus gráficos del dashboard en Report Designer. Añade texto, tablas SQL, imágenes e indicadores y organiza la hoja con una previa del movimiento.

  • Ancho, márgenes y tamaños con ajuste en vivo.
  • Deshacer y rehacer cambios de diseño.
  • Plantillas que guardan el SQL y la distribución.
Explorar la edición y los atajos

El resultado también puede salir de DBeaver.

Exporta un HTML interactivo que se abre sin conexión o guarda un borrador EML con los gráficos como imágenes. Las exportaciones compartibles omiten el SQL y las referencias de conexión.

El borrador se guarda como archivo; BeaverCanvas no envía el correo.

Pruébalo en tu DBeaver.

Beta 0.6.6. Probada en DBeaver Community 26.2.2, Windows y Linux x86_64.

Descargar ZIP

  1. Descarga el plugin

    Guarda el ZIP de BeaverCanvas de la versión publicada, sin descomprimirlo.

  2. Añade el archivo

    En DBeaver, abre Help → Install New Software → Add → Archive y selecciona el ZIP.

  3. Instala y reinicia

    Selecciona BeaverCanvas Plugin for DBeaver Desktop. Completa el asistente y reinicia DBeaver.

Para empezar, ejecuta un SELECT y abre la pestaña BeaverCanvas del resultado. Desde tu dashboard puedes abrir Report Designer.

Antes de instalar la beta

El plugin todavía no tiene firma digital. Revisa los avisos del instalador y descarga siempre desde este repositorio. macOS y la visualización en cada cliente de correo aún no están certificados. Las plantillas conservan las consultas; abrirlas no autoriza su ejecución.
