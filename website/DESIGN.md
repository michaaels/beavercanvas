# BeaverCanvas project page

Audience: DBeaver Desktop users who want to turn SQL results into dashboards and reports.
Primary job: show the real product, then make installing its beta unambiguous.

Palette: river blue #087AF5; navy #102E4C; ink #20364B; canvas #F3F7FC;
paper #FFFFFF; muted #53677B. System Segoe UI carries the desktop identity;
large semibold headings establish hierarchy, ordinary body text explains actions.

Left-aligned text, generous image space, no automatic motion:

```
beaver + BeaverCanvas                  Features / Install / GitHub
SQL dashboards and reports.            real dashboard screenshot
Inside DBeaver.                        (dominant product surface)
download / installation
-------------------- dashboard details + map editor ----------------
real report screenshot                 author / adjust / export
-------------------- three installation steps ----------------------
beta scope, source, license and independent project credits
```

Review: a generic dashboard landing page could use invented graphs and repeated
feature cards. Use committed product screenshots instead, with a single large
dashboard hero and alternating editorial sections. Keep installation numbered
because it is a sequence. The beaver illustration is the only decorative accent.

Assets are copied from their canonical plugin/docs locations at build time.
No fonts, scripts, trackers or CDN resources are loaded from external services.
All core content and installation links work without JavaScript.
